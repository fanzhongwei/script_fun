# AI 图片水印去除

本机 Python CLI 工具：针对 AI 生成图片角落半透明文字水印（如「豆包AI生成」），自动检测（OCR + 关键词）并用 LaMa 修复，支持单张/小批量、预览确认与手动区域兜底。

适用于 `image_exporter` 下载商品图后、`pdd_product_importer` 导入前的本地预处理。

## 环境依赖说明

- **操作系统**：Linux / macOS / Windows
- **Python**：3.9+（推荐使用本机隔离环境 `python3-dev` / `pip3-dev`）
- **硬件**：本机 CPU 即可，无需 GPU
- **首次运行**：LaMa 模型会自动下载（约 200MB），EasyOCR 模型首次也会下载
- **LaMa 引擎**：使用 `simple-lama-inpainting`（比 lama-cleaner 依赖更轻）

### 安装步骤

`pip3-dev` / `python3-dev` 已默认使用清华大学 PyPI 镜像（配置见 `/home/develop/python/pip.conf`），国内下载更快。

```bash
# 1. 激活开发环境（若已配置 /home/develop/python）
source /home/develop/python/venvs/python-dev/bin/activate
# 或直接使用 python3-dev / pip3-dev

# 2. 安装 PyTorch CPU 版（镜像已含 pytorch-wheels/cpu，直接安装即可）

```

若需临时改用官方源：

```bash

```

## 脚本参数说明

| 参数 | 说明 | 示例 |
|------|------|------|
| `-i`, `--input` | 输入图片或目录（必填） | `-i photo.png` / `-i ./ai_images/` |
| `-o`, `--output` | 输出文件或目录（必填） | `-o clean.png` / `-o ./clean/` |
| `--preview` | 仅输出 mask 预览，不修复 | `--preview` |
| `--region` | 手动区域，跳过 OCR | `--region br` / `--region 0.75,0.85,1.0,1.0` |
| `--config` | 自定义 patterns.yaml | `--config ./my-patterns.yaml` |
| `--engine` | 修复引擎：`lama`（默认）或 `opencv` | `--engine opencv` |
| `--force` | 批量模式下覆盖已存在输出 | `--force` |

### 使用示例

```bash
# 单张：自动检测 + LaMa 修复
python3-dev watermark_remover.py -i input.png -o output.png

# 预览 mask（推荐首次使用）
python3-dev watermark_remover.py -i input.png --preview -o ./preview/

# 批量目录
python3-dev watermark_remover.py -i ./ai_images/ -o ./clean/

# OCR 未命中时，手动指定右下角落
python3-dev watermark_remover.py -i input.png -o output.png --region br

# 手动比例坐标 (x1,y1,x2,y2，相对 0~1)
python3-dev watermark_remover.py -i input.png -o output.png --region 0.75,0.85,1.0,1.0

# OpenCV 降级修复（更快但效果较差）
python3-dev watermark_remover.py -i input.png -o output.png --engine opencv
```

### 预览输出文件

`--preview` 模式下会在 `-o` 指定目录生成：

- `{文件名}.mask.png` — mask 红色叠加预览
- `{文件名}.mask.bin.png` — 纯二值 mask

## 使用配置说明

默认配置文件为同目录下的 `patterns.yaml`：

```yaml
roi:
  width_ratio: 0.25    # 角落 ROI 宽占整图比例
  height_ratio: 0.15   # 角落 ROI 高占整图比例
  padding_px: 5        # OCR bbox 外扩像素

corner_priority:       # 扫描顺序
  - br
  - bl
  - tr
  - tl

keywords:              # AI 水印关键词（子串匹配，长词优先）
  - 豆包AI生成
  - 豆包
  - 即梦AI
  - 即梦
  - 通义万相
  - 文心一格
  - AI生成
  - AI作图
  - Generated by

# OCR 误识别兜底（正则，子串未命中时使用）
keyword_patterns:
  - "豆.{0,4}生成"
  - "即梦"
  - "AI.{0,2}生成"
  - "Generated by"
```

新增 AI 平台水印时，只需在 `keywords` 中添加对应短语，无需修改代码。

## FAQ 说明

### OCR 漏检怎么办？

1. 先用 `--preview` 查看是否生成 mask
2. 在 `patterns.yaml` 的 `keywords` 中添加新平台关键词
3. 使用 `--region br` 手动指定右下角落，或 `--region x1,y1,x2,y2` 精确框选

### 修复后有留痕/色差？

- 复杂纹理背景（如红色地面、丝带）LaMa 效果优于 OpenCV，但仍可能有轻微痕迹
- 先用 `--preview` 确认 mask 范围是否过大（误含正文）
- 可缩小 `--region` 范围，仅覆盖水印文字区域

### 处理速度如何？

- 本机 CPU 下 LaMa 约 30 秒～2 分钟/张（视图片尺寸而定）
- 十几张规模可接受；若仅需快速验证可用 `--engine opencv`

### 会误删图片正文吗？

- 检测仅扫描四个角落 ROI，并匹配 AI 水印关键词白名单
- 画面中央的大标题（如「情侣手绳」）通常不会被误检
- 建议首次批量处理前用 `--preview` 确认

### 支持哪些图片格式？

输入支持：`.png`、`.jpg`、`.jpeg`、`.webp`

## 桌面 GUI

PySide6 图形界面：选图后**自动后台批量处理**，缩略图预览，手动矩形框选（不依赖 OCR 关键词），导出时使用**原图全分辨率**修复。

### GUI 安装与启动

```bash
cd python/watermark_remover
pip3-dev install -r requirements.txt

python3-dev -m gui
```

### GUI 操作流程

1. **选择文件** / **选择文件夹** → 自动入队处理
2. 列表切换图片：已处理显示双栏预览；处理中显示 loading
3. 自动失败或不满意：拖拽**矩形框选** → **生成预览**
4. 手动框选后须点 **确认** 才可导出；自动成功的可直接导出
5. **导出当前** / **导出全部**（跳过未就绪项并提示数量）

打包见 `packaging/README.md`（Linux / Windows 全量离线包）。
