## Purpose

跨平台桌面 GUI（Linux / Windows）：用户选择图片后自动后台批量去水印，缩略图预览与切换，手动矩形框选去除任意区域（需确认），全分辨率导出；全量离线安装包，无需用户自行安装 Python。

## ADDED Requirements

### Requirement: 选择文件或文件夹并自动批量处理

应用 SHALL 提供「选择文件」与「选择文件夹」入口。用户选入后，应用 SHALL 立即将所有支持的图片（`.png`、`.jpg`、`.jpeg`、`.webp`）加入后台处理队列并开始自动处理，无需用户额外选择批量模式或点击「开始处理」。

#### Scenario: 选择多个文件后自动入队

- **WHEN** 用户通过文件选择器选中 3 张图片并确认
- **THEN** 列表显示 3 项且后台队列开始按序自动处理

#### Scenario: 选择文件夹后自动入队

- **WHEN** 用户选择包含 5 张支持格式图片的文件夹
- **THEN** 5 张图片全部入队并自动处理

### Requirement: 列表状态与切换时的 loading

应用 SHALL 在侧栏列表展示每张图片的处理状态（排队中、处理中、自动完成、自动失败、待手动确认、可导出）。用户切换到「处理中」或「排队中」的图片时，主视图 SHALL 显示 loading 提示（如「正在处理…」）；该项处理完成后 SHALL 自动刷新为预览视图。

#### Scenario: 切换到处理中的图片

- **WHEN** 用户点击状态为「处理中」的列表项
- **THEN** 主视图显示 loading，且不展示完整修复预览

#### Scenario: 处理完成后自动刷新当前项

- **WHEN** 用户正查看某张 processing 中的图片且该任务完成
- **THEN** loading 消失并显示原图缩略与修复预览缩略

#### Scenario: 切换到已完成的图片

- **WHEN** 用户点击状态为「自动完成」的列表项
- **THEN** 立即显示缓存的缩略预览，无 loading

### Requirement: 自动检测路径与失败行为

后台自动处理 SHALL 使用 OCR 与配置文件关键词/正则检测 AI 水印并生成 mask，再生成缩略修复预览。若自动检测未命中，该图片 SHALL 标记为「自动失败」，SHALL NOT 自动使用默认角落区域进行修复。

#### Scenario: 自动检测成功

- **WHEN** 某图片右下角 OCR 命中配置的关键词或正则
- **THEN** 该图片标记为自动完成并展示缩略修复预览

#### Scenario: 自动检测失败无默认修复

- **WHEN** 某图片四角均未命中关键词或正则
- **THEN** 该图片标记为自动失败，不生成修复预览，并提示用户可手动框选

### Requirement: 手动矩形框选（独立于关键词）

应用 SHALL 在原图视图上支持用户拖拽绘制单个矩形选区。手动框选 SHALL 不依赖 OCR 或内置水印关键词，矩形区域即修复 mask。用户点击「生成预览」后，应用 SHALL 基于该 mask 生成缩略修复预览。

#### Scenario: 对失败项手动框选并预览

- **WHEN** 用户对自动失败图片框选水印区域并点击「生成预览」
- **THEN** 系统跳过 OCR，按矩形 inpaint 并显示缩略预览

#### Scenario: 手动框选覆盖自动结果

- **WHEN** 用户对自动完成图片重新框选并生成预览
- **THEN** 新手动 mask 覆盖原自动 mask 用于后续导出

#### Scenario: 仅支持单个矩形

- **WHEN** 用户已有一个矩形框选再次拖拽新矩形
- **THEN** 新矩形替换旧矩形（同时仅存在一个选区）

### Requirement: 手动路径显式确认

对通过手动框选生成预览的图片，应用 SHALL 显示「确认」按钮；用户 MUST 点击确认后该图片才变为可导出状态。自动检测成功的图片 SHALL NOT 要求额外确认即可导出。

#### Scenario: 手动预览后未确认不可导出

- **WHEN** 用户手动框选并生成预览但未点击确认
- **THEN** 「导出当前」对该图不可用或提示需先确认

#### Scenario: 手动确认后可导出

- **WHEN** 用户手动框选、生成预览并点击确认
- **THEN** 该图标记为可导出

#### Scenario: 自动成功直接可导出

- **WHEN** 某图片自动检测并预览成功
- **THEN** 用户无需点击确认即可导出该图

### Requirement: 缩略预览与原图全分辨率导出

界面预览 SHALL 基于缩略图（最长边不超过约定上限，如 1024px）展示原图与修复结果。导出时，应用 SHALL 将 mask 映射到原图分辨率并对原图执行全分辨率 inpaint，写入用户指定路径。

#### Scenario: 预览使用缩略图

- **WHEN** 用户在列表中查看已处理图片
- **THEN** 主视图展示的是缩略级别的原图与修复对比，而非加载全尺寸像素

#### Scenario: 导出全分辨率

- **WHEN** 用户对某可导出图片执行导出
- **THEN** 输出文件的像素尺寸与原始文件一致，且修复区域基于原图 mask 计算

### Requirement: 导出当前与导出全部

应用 SHALL 提供「导出当前」与「导出全部」；仅可导出状态为「自动完成可导出」或「手动已确认可导出」的图片。自动失败且未手动修复的图片 SHALL NOT 被包含在导出全部中。

#### Scenario: 导出当前

- **WHEN** 用户选中可导出图片并点击导出当前且选择输出路径
- **THEN** 全分辨率修复图写入该路径

#### Scenario: 导出全部跳过未完成项

- **WHEN** 队列中有 2 张自动失败未处理、3 张可导出，用户点击导出全部
- **THEN** 仅 3 张可导出图片写入目标文件夹，并提示跳过数量

### Requirement: 跨平台全量离线安装包

项目 SHALL 提供 Linux 与 Windows 的打包方案，安装/解压后用户无需单独安装 Python 或 pip 依赖即可双击运行。安装包 SHALL 内置 LaMa 与 OCR 所需模型文件，首次运行不依赖网络下载模型。

#### Scenario: Linux 双击运行

- **WHEN** Linux 用户获得发布包（AppImage 或等价物）并启动
- **THEN** GUI 正常打开且可在无 Python 环境的机器上完成选图与导出

#### Scenario: Windows 双击运行

- **WHEN** Windows 用户安装或解压发布包并启动 exe
- **THEN** GUI 正常打开且可在无 Python 环境的机器上完成选图与导出

### Requirement: GUI 使用说明

`python/watermark_remover/` 下 README 或独立 GUI 说明 SHALL 补充：桌面版启动方式、选图与预览流程、手动框选与确认规则、导出说明、Linux/Windows 安装包获取与构建概要。

#### Scenario: 文档覆盖 GUI 流程

- **WHEN** 用户阅读 README 中 GUI 章节
- **THEN** 可了解自动批量、loading、手动框选、确认与导出的完整操作路径
