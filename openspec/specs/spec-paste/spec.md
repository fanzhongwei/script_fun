# spec-paste Specification

## Purpose
在拼多多商家后台商品规格编辑页，使用户可在第一个规格名称输入框一次性粘贴多个规格值，脚本自动拆分并依次填充所有规格框，减少重复手工输入。
## Requirements
### Requirement: 脚本仅在拼多多商家后台生效

脚本 MUST 仅匹配 `*://mms.pinduoduo.com/*` URL，在商品规格编辑相关页面运行。

#### Scenario: 访问商家后台

- **WHEN** 用户在 `mms.pinduoduo.com` 打开商品规格编辑页
- **THEN** 脚本加载并监听规格名称输入框的粘贴事件

#### Scenario: 访问其他站点

- **WHEN** 用户访问非 `mms.pinduoduo.com` 的页面
- **THEN** 脚本不注入、不修改页面行为

### Requirement: 仅在第一个规格框粘贴时触发批量填充

脚本 MUST 仅当用户在某一规格组内**第一个**「请输入规格名称」输入框执行粘贴时，启动批量填充；在其他规格框或非规格 input 粘贴时 MUST NOT 拦截或修改默认粘贴行为。

#### Scenario: 在第一个规格框粘贴

- **WHEN** 焦点位于某规格组第一个 `placeholder="请输入规格名称"` 的 input 且用户粘贴文本
- **THEN** 脚本拦截默认粘贴，按分隔符拆分并依次填充该组所有规格框

#### Scenario: 在非第一个规格框粘贴

- **WHEN** 焦点位于同组第二个及之后的规格名称 input 且用户粘贴
- **THEN** 浏览器默认粘贴行为保持不变，脚本不介入

### Requirement: 按常见分隔符拆分粘贴文本

脚本 MUST 将粘贴文本按以下分隔符拆分为规格名称列表：空格、逗号、中英文分号、竖线、斜杠、反斜杠、顿号、制表符、换行。拆分后 MUST 去除每项首尾空白、过滤空项，并去除 UTF-8 BOM。

#### Scenario: 逗号分隔

- **WHEN** 用户粘贴 `米色,白色,黑色`
- **THEN** 解析为 `["米色", "白色", "黑色"]` 三个规格名

#### Scenario: 换行分隔

- **WHEN** 用户粘贴含换行的多行文本（如从 Excel 复制）
- **THEN** 每行/每项作为独立规格名参与填充

#### Scenario: 无效内容

- **WHEN** 用户粘贴仅含分隔符或空白的内容
- **THEN** 脚本不修改任何输入框，并提示未识别到有效规格名称

### Requirement: 粘贴时覆盖整组规格

当批量填充启动时，脚本 MUST 从该规格组第一个框起按序写入解析结果；对于超出粘贴项数的已有规格框，MUST 清空其值。已有内容 MUST 被新粘贴内容覆盖，而非追加。

#### Scenario: 覆盖已有规格

- **WHEN** 规格组已有 `米色、白色` 两项，用户在第一个框粘贴 `红色,蓝色,绿色`
- **THEN** 整组依次变为 `红色`、`蓝色`、`绿色`，原有值被替换

#### Scenario: 粘贴项少于已有框数

- **WHEN** 规格组已有 5 个框，用户粘贴 2 个规格名
- **THEN** 前 2 个框写入新值，其余框被清空

### Requirement: 动态等待并依次填充规格框

因页面在填完一项后才渲染下一输入框，脚本 MUST 在写入每一项后等待下一输入框出现，再写入下一项。等待 MUST 有超时上限；超时后 MUST 停止填充并报告已填项数与未填项数。

#### Scenario: 顺序填充动态增行

- **WHEN** 用户粘贴 4 个规格名且页面初始仅 1 个输入框
- **THEN** 脚本依次填入第 1～4 个框，每填一项后等待新框出现再继续

#### Scenario: 等待超时

- **WHEN** 写入某一项后超过超时时间仍未出现下一输入框
- **THEN** 脚本停止后续填充，并提示已填充数量与剩余未填数量

### Requirement: 正确写入 React 受控输入框

脚本 MUST 通过触发 input 的 value 变更及 `input`、`change` 事件，使 beast-core 受控组件识别填充值；不得仅设置 DOM `value` 而不触发事件。

#### Scenario: 填充后页面识别值

- **WHEN** 脚本向规格名称 input 写入 `藏青色`
- **THEN** 输入框显示 `藏青色` 且页面逻辑视其为有效输入（可触发后续增行）

### Requirement: 填充过程防重入

批量填充进行中，脚本 MUST 忽略新的粘贴触发，直至当前填充流程结束，避免并发写入导致顺序错乱或重复填充。

#### Scenario: 填充中再次粘贴

- **WHEN** 批量填充尚未完成时用户再次粘贴
- **THEN** 第二次粘贴被忽略，第一次填充流程继续执行

### Requirement: 填充结果用户提示

填充结束或失败时，脚本 MUST 向用户展示简要 toast 提示，包括：成功填充项数、部分超时未填项数、或无有效规格名。

#### Scenario: 全部成功

- **WHEN** 4 个规格名均成功填入
- **THEN** 提示已填充 4 项规格

#### Scenario: 部分失败

- **WHEN** 6 个规格名中仅成功填入 4 个后超时
- **THEN** 提示已填充 4 项、剩余 2 项未填入
