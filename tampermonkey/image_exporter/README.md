# 页面图片导出器

Tampermonkey 用户脚本：在任意网页右侧提供「导出图片」入口，扫描 `<img>` 与 CSS `background-image`，以 200×200 缩略图平铺展示，复选后按用户指定的文件夹名批量下载到浏览器默认下载目录的子文件夹中。

## 环境依赖说明

- **浏览器**：Chrome、Edge、Firefox 等支持用户脚本的现代浏览器
- **扩展**：Tampermonkey（推荐）或 Violentmonkey
- **权限**：脚本需申请 `GM_download`（批量下载到本地）
- **系统**：Windows / macOS / Linux 均可；下载路径由浏览器下载设置决定

## 脚本参数说明

本脚本为浏览器用户脚本，**无命令行参数**。可在 Tampermonkey 管理面板中查看/编辑以下元数据：

| 元数据 | 说明 | 默认值 |
|--------|------|--------|
| `@match` | 脚本生效的 URL 匹配规则 | `*://*/*`（所有 http/https 页面） |
| `@grant GM_download` | 批量下载到本地 | 必需 |
| `@run-at` | 注入时机 | `document-idle` |

如需仅在特定站点启用，可将 `@match` 改为例如 `*://*.example.com/*`。

## 使用配置说明

### 1. 安装脚本

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 打开 `image_exporter.user.js`，Tampermonkey 会提示安装；或在扩展中选择「添加新脚本」并粘贴内容
3. 保存并确保脚本已启用

### 2. 浏览器下载设置（重要）

方案 B 依赖 `GM_download` 的 `name` 字段中的子路径（`文件夹名/文件名`）：

- **Chrome / Edge**：在 Tampermonkey 设置中确认允许下载；若子文件夹未生效，检查浏览器是否将文件保存到默认 Downloads 目录
- 建议关闭「下载前询问每个文件的保存位置」，以免批量下载时频繁弹窗

### 3. 使用流程

1. 打开目标网页（懒加载页面建议先滚动加载完图片）
2. 点击页面右侧悬浮按钮 **「导出图片」**
3. 在面板中查看发现的图片（默认全选）
4. 在 **文件夹名** 输入框中填写子文件夹名称（默认预填为清理后的页面标题，可修改）
5. 取消不需要的图片勾选，或点击「全选 / 取消全选」
6. 点击 **「下载选中」**，完成后查看面板底部成功/失败统计

### 4. 目录结构

```
tampermonkey/image_exporter/
├── image_exporter.user.js   # 用户脚本
└── README.md                # 本说明
```

下载结果示例（浏览器默认下载目录下）：

```
Downloads/
└── 我的页面标题/
    ├── photo1.jpg
    ├── banner.png
    └── image_3.webp
```

## FAQ 说明

### Q1：为什么有些图片下载失败？

可能原因：

- 图片 URL 有防盗链或需要登录 Cookie
- CDN 禁止跨域直接下载
- 网络超时

脚本会在面板底部显示成功与失败数量。可尝试在能正常打开图片的页面上再导出，或手动保存失败的单张图片。

### Q2：为什么没有发现某张图片？

- **懒加载**：图片尚未加载时可能只有 `data-src`，脚本会尝试常见懒加载属性；请先滚动页面触发加载后再打开面板
- **Canvas / SVG 内嵌**：本脚本仅处理 URL 类资源（`<img>` 与 CSS `background-image`），不导出 Canvas 绘制或 SVG 内嵌位图
- **动态插入**：若在打开面板后才加载的图片，请关闭面板后重新点击「导出图片」

### Q3：文件夹名有什么限制？

文件夹名不能包含 Windows 非法字符：`\ / : * ? " < > |`。脚本会自动将非法字符替换为 `_`。空文件夹名无法开始下载。

### Q4：子文件夹没有创建，文件都在 Downloads 根目录？

部分浏览器或 Violentmonkey 版本对 `GM_download` 的 `name` 子路径支持不一致。请确认：

- 使用 Tampermonkey 最新版
- 扩展已获得下载相关权限
- 若仍无效，文件会以 `文件夹名_文件名` 或扁平名称保存，请查阅所用扩展文档

### Q5：会不会影响原网页功能？

脚本 UI 使用独立容器与高 z-index，关闭面板后仅保留右侧悬浮按钮，不修改页面原有 DOM 结构（除注入脚本 UI 外）。

### Q6：如何卸载？

在 Tampermonkey 管理面板中禁用或删除「页面图片导出器」即可。
