# 页面图片导出器

Tampermonkey 用户脚本：在任意网页右侧提供「导出图片」入口，扫描 `<img>` 与 CSS `background-image`，以 200×200 缩略图平铺展示，复选后按用户指定的文件夹名批量下载到浏览器默认下载目录的子文件夹中。

## 环境依赖说明

- **浏览器**：Chrome、Edge、Firefox 等支持用户脚本的现代浏览器
- **扩展**：Tampermonkey（推荐）或 Violentmonkey
- **权限**：脚本需申请 `GM_download`（批量下载到本地）
- **系统**：Windows / macOS / Linux 均可；下载路径由浏览器下载设置决定

## 脚本参数说明

本脚本为浏览器用户脚本，**无命令行参数**。可在 Tampermonkey 管理面板中查看/编辑以下元数据：

| 元数据 | 说明 | 默认值 |
|--------|------|--------|
| `@match` | 脚本生效的 URL 匹配规则 | `*://*/*`（所有 http/https 页面） |
| `@grant GM_download` | 批量下载到本地 | 必需 |
| `@run-at` | 注入时机 | `document-idle` |

如需仅在特定站点启用，可将 `@match` 改为例如 `*://*.example.com/*`。

## 使用配置说明

### 1. 安装脚本

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 打开 `image_exporter.user.js`，Tampermonkey 会提示安装；或在扩展中选择「添加新脚本」并粘贴内容
3. 保存并确保脚本已启用

### 2. 浏览器下载设置（重要）

方案 B 依赖 `GM_download` 的 `name` 字段中的子路径（`文件夹名/文件名`）：

- **Chrome / Edge**：在 Tampermonkey 设置中确认允许下载；若子文件夹未生效，检查浏览器是否将文件保存到默认 Downloads 目录
- 建议关闭「下载前询问每个文件的保存位置」，以免批量下载时频繁弹窗

### 3. 使用流程

1. 打开目标网页（懒加载页面建议先滚动加载完图片）
2. 点击页面右侧悬浮按钮 **「导出图片」**
3. 在面板中查看发现的图片
4. 在 **文件夹名** 输入框中填写子文件夹名称（默认预填为清理后的页面标题，可修改）；也可点击 **轮播图 / 详情图 / 预览图** 快捷单选一键填入
5. 取消不需要的图片勾选，或点击「全选 / 取消全选」；也可在缩略图上**按住鼠标左键滑动**快速多选（详见下方「鼠标划选」）
6. 点击 **「下载选中」**，完成后查看面板底部成功/失败统计

### 5. 鼠标划选多选

导出面板支持类似手机相册的划选操作（仅鼠标，暂不支持 touch）：

1. 在同一模块分组内的缩略图上**按住左键**并向同组其他卡片**滑动**（不支持跨模块划选）
2. 光标经过的每张卡片会**切换一次**选中状态（未选中→选中，已选中→未选中）
3. 同一次滑动中，每张卡片只处理一次，避免来回抖动重复切换
4. 选中图片会**实时显示序号 badge**（与下载文件名顺序一致：1、2、3…）
5. **短距离点击**（移动小于 4 像素）仍视为单击，与划选互不干扰

> 缩略图已禁用浏览器原生拖图行为，避免划选时把图片拖走。

与单击 / 复选框的关系：

| 操作 | 行为 |
|------|------|
| 单击卡片 | 切换该张选中/未选中 |
| 点击复选框 | 切换该张选中/未选中 |
| 鼠标划选 | 经过的卡片各切换一次；再次划选可反选 |
| 全选 / 取消全选 | 批量选中或清空 |

## FAQ 说明

### Q1：为什么有些图片下载失败？

可能原因：

- 图片 URL 有防盗链或需要登录 Cookie
- CDN 禁止跨域直接下载
- 网络超时

脚本会在面板底部显示成功与失败数量。可尝试在能正常打开图片的页面上再导出，或手动保存失败的单张图片。

### Q2：为什么没有发现某张图片？

- **懒加载**：图片尚未加载时可能只有 `data-src`，脚本会尝试常见懒加载属性；请先滚动页面触发加载后再打开面板
- **Canvas / SVG 内嵌**：本脚本仅处理 URL 类资源（`<img>` 与 CSS `background-image`），不导出 Canvas 绘制或 SVG 内嵌位图
- **动态插入**：若在打开面板后才加载的图片，请关闭面板后重新点击「导出图片」

### Q2.1：拼多多商家后台如何分类导出？

在 `mms.pinduoduo.com` 商品编辑页，脚本按页面区块精准采集：

| 类目 | DOM 范围 | 采集目标 |
|------|----------|----------|
| **轮播图** | `#picture` / `#basic.carousel_gallery` | `MaterialModalButton_v2_imageBox` / `imgContainer` / `imageWrapper` 背景图（不含 `#materialPic` 白底图） |
| **详情图** | `#detail_pic` | `img[data-tracking-click-viewid="el_preview_business_details"]` |
| **预览图** | `#goods-spec-sku` / `#sku` | 按 `.sku-preview-cell` 行顺序采集，**不去重**（导出前把滚动层 `max-height/height` 撑到虚拟总高并清 spacer padding，对齐手动改法） |

各类目内按 **DOM 顺序对 URL 去重**（相同链接只保留首次出现）。**轮播图 / 详情图**会额外过滤：DOM 文案含「文本暂无预览」的项，以及短边 &lt; 480px 的图片（含占位小图）。预览图不受该尺寸门槛约束。每个类目区块旁有 **下载全部** 按钮；导出时 **自动使用对应文件夹名**（轮播图 / 详情图 / 预览图），并同步更新顶部文件夹输入框。多类目混合下载选中时，会分别保存到各自文件夹。

**预览图分桶**：当预览图总数 **超过 12 张** 时，下载路径按全局序号每 12 张一组放入区间子文件夹（如 `预览图/1-12/`、`预览图/13-24/`），文件名仍为全局连续序号（`1.jpg` … `12.jpg`、`13.jpg` …）。不超过 12 张时仍为 `预览图/1.jpg` 等扁平结构。部分选中时，序号与子文件夹区间仍按完整预览列表中的位置计算。

### 一键导出与 manifest.json

在拼多多商家后台点击 **「一键导出」**（轮播图 + 详情图 + 预览图 + 成本表）时，脚本会在商品目录 `{商品标题-商品ID}/` 下额外写入 **`manifest.json`**，供 [商品包导入器](../pdd_product_importer/README.md) 使用。manifest 包含：

- 规格维度 `specDimensions`（`typeLabel` 取自 `.goods-spec-row` 内 ST 规格类型下拉框 + `values`）
- 图片相对路径（轮播/详情/预览，预览含全局 `index` 与 `style`）
- Excel 路径（默认 `成本表.xlsx`）

使用 File System Access API 选择保存目录时会直接写入该文件；使用 `GM_download` 回退时会下载到同路径下的 `manifest.json`。

其它站点仍使用通用 DOM 模块扫描，模块内按 URL 去重。

### Q3：文件夹名有什么限制？

文件夹名不能包含 Windows 非法字符：`\ / : * ? " < > |`。脚本会自动将非法字符替换为 `_`。空文件夹名无法开始下载。

### Q4：子文件夹没有创建，文件都在 Downloads 根目录？

部分浏览器或 Violentmonkey 版本对 `GM_download` 的 `name` 子路径支持不一致。请确认：

- 使用 Tampermonkey 最新版
- 扩展已获得下载相关权限
- 若仍无效，文件会以 `文件夹名_文件名` 或扁平名称保存，请查阅所用扩展文档

### Q5：会不会影响原网页功能？

脚本 UI 使用独立容器与高 z-index，关闭面板后仅保留右侧悬浮按钮，不修改页面原有 DOM 结构（除注入脚本 UI 外）。

### Q6：划选时序号 badge 是什么？

选中图片右上角蓝色数字表示下载顺序（保存为 `1.jpg`、`2.png` 等）。划选过程中序号会实时更新；取消选中后 badge 消失，其余序号自动重排。

### Q7：如何卸载？

在 Tampermonkey 管理面板中禁用或删除「页面图片导出器」即可。
