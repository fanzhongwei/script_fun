# 价格计算器

Tampermonkey 用户脚本：在拼多多商家后台（`mms.pinduoduo.com`）SKU 规格页扫描款式列表，按采购成本与活动规则计算拼单价/单买价、投产比等指标，支持 Markdown 导入导出与一键回填。

## 环境依赖说明

- **浏览器**：Chrome、Edge 等支持用户脚本的现代浏览器
- **扩展**：Tampermonkey（推荐）或 Violentmonkey
- **权限**：脚本需申请 `GM_setValue`、`GM_getValue`（悬浮按钮位置持久化）
- **适用站点**：`*://mms.pinduoduo.com/*`（拼多多商家后台）

## 脚本参数说明

本脚本为浏览器用户脚本，**无命令行参数**。可在 Tampermonkey 管理面板中查看/编辑以下元数据：

| 元数据 | 说明 | 默认值 |
|--------|------|--------|
| `@match` | 脚本生效的 URL | `*://mms.pinduoduo.com/*` |
| `@grant GM_setValue` | 保存 FAB 位置 | 必需 |
| `@grant GM_getValue` | 读取 FAB 位置 | 必需 |
| `@run-at` | 注入时机 | `document-idle` |

## 使用配置说明

### 1. 安装脚本

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 打开 `price_calculator.user.js`，Tampermonkey 会提示安装
3. 保存并确保脚本已启用

### 2. 使用流程

1. 打开拼多多商家后台商品规格编辑页（含 SKU 表格：款式、拼单价、单买价）
2. 点击页面右侧悬浮按钮 **「价格计算」**（可拖动）
3. 填写各 SKU **采购成本**；支持在采购成本列粘贴批量数据（逗号/换行/空格等分隔）
4. 按需修改 **运费、退货率、平台扣点、目标利润率**（均为百分比 0～100）
5. 在右侧 **活动区** 设置 **立减优惠券**、**限时限量购**（立减/打折）
6. 查看自动计算的 **实际拼单价、拼单价、单买价** 及 **实际利润、三种投产比**
7. 点击 **【导出】** 复制 Markdown 并下载 `.md` 文件；或 **【导入】** 恢复历史数据
8. 点击 **「回填」** 将拼单价、单买价写入原页面表格

### 3. 计算公式（摘要）

- **实际成本** = 采购成本 + 运费
- **实际拼单价** = ROUND(实际成本 × (1 + 目标利润率/100), 2)
- **拼单价** = 实际拼单价 + 活动优惠价格
- **实际利润** = ROUND(实际拼单价 × (1 - 平台扣点/100) - 采购成本 - 运费, 2)
- **实际利润率** = 实际利润 / 实际成本 × 100%（与目标利润率同为「成本加成」口径，扣除平台扣点后略低于目标值）
- **净保本投产比** = (实际拼单价 / 实际利润) / (1 - 退货率/100)
- **微付费投产比** = 净保本投产比 / 2 + 0.5
- **最佳投产比** = 净保本 × 1.4（实际利润率 > 50%）或 × 2（≤ 50%）
- **单买价** = ROUND(实际拼单价 × 1.1 + 券金额 + 限时加价 + 3～5 随机小数, 2)

默认值：退货率 20%、目标利润率 20%、平台扣点 0.6%。

### 4. Markdown 导入导出

- **导出**：生成 `# {goods_id}-{商品标题}` 标题、活动配置表、SKU 定价表；同时复制剪贴板并下载 `{goods_id}-{商品标题}.md`
- **导入**：选择 `.md` 文件或粘贴 Markdown；按 **款式** 列匹配，恢复活动配置与可编辑字段（采购成本、运费、退货率、平台扣点、目标利润率）

## FAQ 说明

### Q1：为什么扫描不到 SKU 表格？

- 请确认当前页面 URL 为 `mms.pinduoduo.com` 下的商品规格编辑页
- 表格表头需包含「拼单价」列，且至少一列规格属性（款式、颜色、尺寸等）
- 大规格商品使用虚拟滚动表格时，脚本会在**页面加载完成**及打开/刷新计算器时：先滚到底测量虚拟总高度（`paddingTop + 行高 + paddingBottom`），再改 **`TB_body` 内层**那个 `max-height/height + overflow-y: scroll` 的 div（不是外层 `TB_innerMiddle`），并把 spacer 的 `padding-top/bottom` 置 `0`；若仍不完整，可点击「刷新」重试
- 计算器表格第一列为 **序号**，标题也会显示「共 N 个 SKU」

### Q2：回填后页面没有变化？

商家后台多为 React 受控输入框。脚本已通过原生 value 赋值并触发 `input`/`change` 事件。若仍无效，请尝试点击页面其他区域触发校验，或刷新后重试。

### Q3：「率」类字段如何输入？

退货率、平台扣点以 **百分比** 输入，范围 **0～100**（如 20 表示 20%）。**目标利润率** 同样为百分比，仅限制 ≥ 0，可超过 100%（如 500 表示在成本上加价 500%）。实际利润率等为只读，由系统自动计算。

### Q4：款式如何显示？

多规格 SKU（如型号 + 尺寸）会将所有规格列拼接为 `型号 / 尺寸` 形式，作为导入导出匹配键。

### Q5：采购成本如何批量粘贴？

在任意 SKU 行的采购成本框中粘贴，如 `5.94, 6.20, 7.15`；从当前行起依次向下填充。

### Q6：目标利润率与实际利润率为何不一致？

目标利润率用于计算实际拼单价（成本正向加价）；实际利润率 = 实际利润 ÷ 实际成本，是扣除平台扣点后的真实成本利润率，通常略低于目标利润率（例如目标 200%、扣点 0.6% 时实际约 198.2%；目标 20% 时实际约 19.36%）。

### Q7：导入时部分款式未匹配？

导入按款式文本 trim 后全等匹配。若页面 SKU 款式与导出时不一致（如规格拼接规则变化），该行会被跳过并在提示中报告。

### Q8：如何卸载？

在 Tampermonkey 管理面板中禁用或删除「价格计算器」即可。
