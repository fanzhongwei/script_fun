# 价格计算器

Tampermonkey 用户脚本：在拼多多商家后台（`mms.pinduoduo.com`）SKU 规格页扫描款式列表，按成本与活动规则计算拼单价/单买价，并一键回填到原表格。

## 环境依赖说明

- **浏览器**：Chrome、Edge 等支持用户脚本的现代浏览器
- **扩展**：Tampermonkey（推荐）或 Violentmonkey
- **权限**：脚本需申请 `GM_setValue`、`GM_getValue`（悬浮按钮位置持久化）
- **适用站点**：`*://mms.pinduoduo.com/*`（拼多多商家后台）

## 脚本参数说明

本脚本为浏览器用户脚本，**无命令行参数**。可在 Tampermonkey 管理面板中查看/编辑以下元数据：

| 元数据 | 说明 | 默认值 |
|--------|------|--------|
| `@match` | 脚本生效的 URL | `*://mms.pinduoduo.com/*` |
| `@grant GM_setValue` | 保存 FAB 位置 | 必需 |
| `@grant GM_getValue` | 读取 FAB 位置 | 必需 |
| `@run-at` | 注入时机 | `document-idle` |

## 使用配置说明

### 1. 安装脚本

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 打开 `price_calculator.user.js`，Tampermonkey 会提示安装
3. 保存并确保脚本已启用

### 2. 使用流程

1. 打开拼多多商家后台商品规格编辑页（含 SKU 表格：款式、拼单价、单买价）
2. 点击页面右侧悬浮按钮 **「价格计算」**（可拖动）
3. 在弹窗中填写各 SKU **成本（含人工）**；支持在成本列粘贴批量数据（逗号/换行/空格等分隔）
4. 按需修改 **运费、退货率、目标销售利润率、平台扣点**（均为百分比 0～100）
5. 在右侧表头 **全局活动区** 勾选活动并填写金额；时限量购可选「打折」或「立减」
6. 查看每行自动计算的 **拼单价、单买价、利润率**
7. 点击活动区下方 **「回填」**，将所有有效行价格写入原页面表格

### 3. 计算公式（摘要）

- **基础拼单价**：`N = (成本 + 运费) / ((1 - 平台扣点) - 目标利润率 / (1 - 退货率))`
- **单买价**：`ROUND(拼单价 × 1.2 + 5, 2)`
- **互斥活动**：五种立减券可同时勾选，取拼单价最高的一组
- **时限量购**：可与上述活动叠加（立减加价 / 打折反推挂牌价）

默认值参考同目录 `兵兵计算净投产表格(1).xlsx`：退货率 20%、目标销售利润率 20%、平台扣点 0.6%。

## FAQ 说明

### Q1：为什么扫描不到 SKU 表格？

- 请确认当前页面 URL 为 `mms.pinduoduo.com` 下的商品规格编辑页
- 表格表头需同时包含「款式」与「拼单价」列
- 若页面使用虚拟滚动，请先滚动加载全部 SKU 后点击「刷新」

### Q2：回填后页面没有变化？

商家后台多为 React 受控输入框。脚本已通过原生 value 赋值并触发 `input`/`change` 事件。若仍无效，请尝试点击页面其他区域触发校验，或刷新后重试。

### Q3：「率」类字段如何输入？

退货率、目标销售利润率、平台扣点均以 **百分比** 输入，范围 **0～100**（如 20 表示 20%，0.6 表示 0.6%）。利润率为只读，由系统自动计算。

### Q4：同时勾选多个优惠券如何计算？

五种立减券互斥生效：分别按 Excel 公式计算候选价格，取 **拼单价最高** 的一组（最保守定价）。时限量购在结果上继续叠加。

### Q5：成本如何批量粘贴？

在任意 SKU 行的成本框中粘贴，如 `5.94, 6.20, 7.15` 或换行分隔；从当前行起依次向下填充。超出剩余行数的条目会丢弃并提示。

### Q6：如何卸载？

在 Tampermonkey 管理面板中禁用或删除「价格计算器」即可。
