# 1688 库存检查

Tampermonkey 用户脚本：在 1688 轻应用容器内的爱用分销「商品管理 / 关联货源」页，于「批量关联货源」后注入「库存检查」。逐件打开规格匹配页，核对店铺 SKU 与货源库存、货源价，再返回列表。货源价按店铺记在油猴本地，下次对比涨跌。结果按店铺导出四张 Sheet。

## 环境依赖说明

- **浏览器**：Chrome、Edge 等支持用户脚本的现代浏览器
- **扩展**：[Tampermonkey](https://www.tampermonkey.net/)（推荐）或 Violentmonkey
- **权限**：`GM_getValue`、`GM_setValue`（按店铺记住货源价）。通过 `@require` 加载 `xlsx-js-style`（支持冻结窗格与单元格样式）生成 Excel
- **适用站点**：`*://light-app.1688.com/*`（含该地址作为 iframe 的文档）。须能看到「批量关联货源」按钮
- **目标页示例**：[爱用分销商品设置（拼多多渠道）](https://light-app.1688.com/html/isv-container.html?appKey=6541416&_conanVisible_=false&isLapp=true&jumpFunction=lapp_distribute_tool&state=%7B%22scene_type%22%3A%22ai_workbench%22%2C%22page_code%22%3A%22goods_settings%22%2C%22channel%22%3A%22pinduoduo%22%2C%22shopCode%22%3A%22982897357%22%7D)

## 脚本参数说明

本脚本为浏览器用户脚本，**无命令行参数**。可在脚本顶部修改常量（Tampermonkey 编辑器）：

| 常量 | 说明 | 默认值 |
|------|------|--------|
| `LOW_STOCK_THRESHOLD` | 货源库存 ≤ 该值视为库存告急 | `20` |
| `MAX_PRODUCT_RETRIES` | 单件商品失败后的重试次数（含首次） | `5` |
| `BETWEEN_PRODUCTS_MS` | 返回列表后再检查下一件商品前的停顿 | `1500` |
| `BETWEEN_SHOPS_MS` | 切换店铺前的停顿 | `1500` |

| 元数据 | 说明 | 默认值 |
|--------|------|--------|
| `@match` | 脚本生效 URL | `*://light-app.1688.com/*` |
| `@run-at` | 注入时机 | `document-idle` |
| `@require` | 生成 Excel | jsDelivr `xlsx-js-style` |
| `@grant` | 本地货源价 | `GM_getValue`、`GM_setValue` |

## 使用配置说明

### 1. 安装脚本

1. 安装 Tampermonkey
2. 打开 `stock_checker.user.js`，按提示安装并启用

### 2. 使用流程

1. 打开爱用分销商品管理（关联货源）页，确认「商品状态」等筛选无需改动（脚本不会改筛选）
2. 在「批量关联货源」右侧点击 **库存检查**
3. 页面**右上角浮层**显示进度（本店第几个/本店共多少件；当前商品为「店铺名 · 店铺商品名」；规格页上显示正在核对的 SKU）
4. 脚本按店铺下拉逐店检查，每店翻完商品列表。每一件商品进入规格匹配页读完全部规格和货源卡片价格后返回列表，再检查下一件。同一商品失败会重试，最多 5 次；仍失败则记一行「检查失败」并继续
5. 已读到的货源价按店铺记在油猴本地。第一次只有「首次」，下次才会对比涨跌。检查失败的商品不改已存的价
6. 结束后浮层展示总结（含耗时、涨价/降价/换绑），点击 **下载 Excel**（按店铺依次各下一份，间隔约 2 秒）

### 3. 扫描范围

点击后扫描**店铺下拉中的全部店铺**；每个店铺按当前筛选检查商品列表**所有分页**上带「规格匹配」的商品。不改「商品状态」等筛选。规格匹配页不翻页。

### 4. 检查结果

| 结果 | 含义 | 进入「待处理库存」 |
|------|------|-------------------|
| 库存异常 | 未关联且上架且店库存>0；或已关联且上架且店库存>货源库存 | 是 |
| 库存告急 | 已关联、店库存 > 0、货源库存 ≤ 20（且未被更前规则命中） | 是 |
| 补充库存 | 已关联、店库存=0、货源库存>20 | 是 |
| 关联异常 | 未关联且店库存=0 或未上架；或已关联但 SKU 下架且店库存>0 | 否 |
| 库存正常 | 已关联且未命中以上 | 否 |
| 检查失败 | 同一商品连续 5 次未能完成规格核对 | 否（只在库存明细） |

涨跌与库存结果分开，不改变上表判定。取值：`涨价`、`降价`、`持平`、`首次`、`无货源价`、`换绑`。货源 SKU 名变了记为换绑（仍写出涨跌额）。没有本次货源价时保留上次价。

| 涨跌 | 进入「待处理价格」 |
|------|-------------------|
| 涨价、降价、换绑 | 是 |
| 持平、首次、无货源价 | 否 |

Excel 按店铺各下一份（文件名含店铺名，表内无店铺名列），四个 Sheet：

- **待处理库存**、**库存检查结果明细**：列仍为店铺商品ID、店铺商品名、店铺SKU名、店铺库存、是否上架、检查结果、货源库存、货源SKU名、货源名称、货源供应商。库存异常整行红底，库存告急整行黄底。
- **待处理价格**、**价格检查明细**：列为店铺商品ID、店铺商品名、店铺SKU名、货源SKU名、上次货源价、本次货源价、涨跌、涨跌额、货源名称、货源供应商。涨价红字、降价绿字、换绑橙字，只涂「涨跌」单元格。检查失败不进入价格表。

同一商品的「店铺商品ID」「店铺商品名」「货源名称」「货源供应商」会合并单元格（上下居中）。每个 Sheet **冻结第一行**。列宽按列头设置（能看全表头即可）。

## FAQ 说明

### Q1：页面没有「库存检查」按钮？

确认 Tampermonkey 已启用本脚本，且当前文档 URL 为 `light-app.1688.com`。若业务在 iframe 里，请在能看到「批量关联货源」的那一层检查脚本是否注入（不要勾选油猴的「仅在顶层运行 / noframes」）。

### Q2：会检查多少商品、会切店吗？

会。全部店铺、每店全部商品列表页。全量较耗时，请保持页面不要手动乱点。

### Q3：下载 Excel 失败？

需能加载 `@require` 的 SheetJS。若 CDN 不可用，把 `@require` 换成可访问的 `xlsx-js-style` 地址。

浏览器可能拦截连续多文件下载，请在浏览器里允许下载。多店会间隔约 2 秒各下一份。

### Q4：会改关联或同步库存吗？

不会改关联或同步库存。检查会打开规格匹配页只读，然后返回列表。不点「关联多货源」「更换货源」及底部同步按钮，不改「商品状态」筛选。

### Q5：如何卸载？

在 Tampermonkey 中禁用或删除「1688库存检查」。

### Q6：一进规格匹配就回到列表？

请确认油猴里脚本版本 ≥ 1.1.3。旧版会沿 React 父节点找点击回调，可能点到面包屑返回。更新后重试。

### Q7：货源价存在哪里？换浏览器还在吗？

存在当前浏览器的 Tampermonkey 里，按店铺分开，不上传到 NAS 或其他远端。换浏览器或重装油猴后没有上次价，下一次检查会全部记为「首次」。

### Q8：检查完一件商品后，商品列表跳到第 2 页？

在规格匹配页里跳页是旧版 bug（请用 ≥ 1.1.5）。**1.2.0** 起：只有已经回到商品列表后，才会翻商品列表下一页（全量需要这样）。规格匹配页仍然不会点分页。
