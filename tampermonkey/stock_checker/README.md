# 1688 库存检查

Tampermonkey 用户脚本：在 1688 轻应用容器内的爱用分销「商品管理 / 关联货源」页，于「批量关联货源」后注入「库存检查」，按规格匹配页 SKU 核对店铺库存与货源库存，并导出双 Sheet Excel。

## 环境依赖说明

- **浏览器**：Chrome、Edge 等支持用户脚本的现代浏览器
- **扩展**：[Tampermonkey](https://www.tampermonkey.net/)（推荐）或 Violentmonkey
- **权限**：无需 `@grant`；通过 `@require` 加载 `xlsx-js-style`（支持冻结窗格与单元格样式）生成 Excel
- **适用站点**：`*://light-app.1688.com/*`（含该地址作为 iframe 的文档）。须能看到「批量关联货源」按钮
- **目标页示例**：[爱用分销商品设置（拼多多渠道）](https://light-app.1688.com/html/isv-container.html?appKey=6541416&_conanVisible_=false&isLapp=true&jumpFunction=lapp_distribute_tool&state=%7B%22scene_type%22%3A%22ai_workbench%22%2C%22page_code%22%3A%22goods_settings%22%2C%22channel%22%3A%22pinduoduo%22%2C%22shopCode%22%3A%22982897357%22%7D)

## 脚本参数说明

本脚本为浏览器用户脚本，**无命令行参数**。可在脚本顶部修改常量（Tampermonkey 编辑器）：

| 常量 | 说明 | 默认值 |
|------|------|--------|
| `LOW_STOCK_THRESHOLD` | 货源库存 ≤ 该值视为库存告急 | `20` |
| `BETWEEN_PRODUCTS_MS` | 返回列表后再检查下一件商品前的停顿 | `1500` |
| `BETWEEN_SHOPS_MS` | 切换店铺前的停顿 | `1500` |

| 元数据 | 说明 | 默认值 |
|--------|------|--------|
| `@match` | 脚本生效 URL | `*://light-app.1688.com/*` |
| `@run-at` | 注入时机 | `document-idle` |
| `@require` | 生成 Excel | jsDelivr `xlsx-js-style` |

## 使用配置说明

### 1. 安装脚本

1. 安装 Tampermonkey
2. 打开 `stock_checker.user.js`，按提示安装并启用

### 2. 使用流程

1. 打开爱用分销商品管理（关联货源）页，确认「商品状态」等筛选无需改动（脚本不会改筛选）
2. 在「批量关联货源」右侧点击 **库存检查**
3. 页面**右上角浮层**显示进度（本店第几个/本店共多少件；当前商品为「店铺名 · 店铺商品名」；进入规格匹配后还会显示当前 SKU 名）
4. 脚本按店铺下拉逐店检查：每店翻完商品列表，进入「规格匹配」，切换到「全部规格」页签、取消「仅查看上架中的商品规格」，读完当前规格表后返回（规格匹配页无分页）
5. 结束后浮层展示总结（含耗时），点击 **下载 Excel**（按店铺依次各下一份，间隔约 2 秒）

### 3. 扫描范围

点击后扫描**店铺下拉中的全部店铺**；每个店铺按当前筛选检查商品列表**所有分页**上带「规格匹配」的商品。不改「商品状态」等筛选。规格匹配页不翻页。

### 4. 检查结果

| 结果 | 含义 | 进入「待处理库存」 |
|------|------|-------------------|
| 库存异常 | 未关联且上架且店库存>0；或已关联且上架且店库存>货源库存 | 是 |
| 库存告急 | 已关联、店库存 > 0、货源库存 ≤ 20（且未被更前规则命中） | 是 |
| 补充库存 | 已关联、店库存=0、货源库存>0 | 是 |
| 关联异常 | 未关联且店库存=0 或未上架；或已关联但 SKU 下架且店库存>0 | 否 |
| 库存正常 | 已关联且未命中以上 | 否 |
| 检查失败 | 该商品 5 次仍无法完成规格核对 | 否（仅明细） |

Excel 按店铺各下一份（文件名含店铺名，表内无店铺名列）。两个 Sheet 列相同：

店铺商品ID、店铺商品名、店铺SKU名、店铺库存、是否上架、检查结果、货源库存、货源SKU名、货源名称、货源供应商。

同一商品的「店铺商品ID」「店铺商品名」「货源名称」「货源供应商」会合并单元格（上下居中）。每个 Sheet **冻结第一行**。列宽按列头设置（能看全表头即可）。**库存异常**整行红底，**库存告急**整行黄底（两个 Sheet 都涂）。

## FAQ 说明

### Q1：页面没有「库存检查」按钮？

确认 Tampermonkey 已启用本脚本，且当前文档 URL 为 `light-app.1688.com`。若业务在 iframe 里，请在能看到「批量关联货源」的那一层检查脚本是否注入（不要勾选油猴的「仅在顶层运行 / noframes」）。

### Q2：会检查多少商品、会切店吗？

会。全部店铺、每店全部商品列表页。全量较耗时，请保持页面不要手动乱点。

### Q3：下载 Excel 失败？

需能加载 `@require` 的 SheetJS。若 CDN 不可用，把 `@require` 换成可访问的 `xlsx-js-style` 地址。

浏览器可能拦截连续多文件下载，请在浏览器里允许下载。多店会间隔约 2 秒各下一份。

### Q4：会改关联或同步库存吗？

不会。只点击规格匹配查看数据并返回，不点「关联多货源」「更换货源」及底部同步按钮，也不改「商品状态」筛选。

### Q5：如何卸载？

在 Tampermonkey 中禁用或删除「1688库存检查」。

### Q6：一进规格匹配就回到列表？

请确认油猴里脚本版本 ≥ 1.1.3。旧版会沿 React 父节点找点击回调，可能点到面包屑返回。更新后重试。

### Q7：检查完一件商品后，商品列表跳到第 2 页？

在规格匹配页里跳页是旧版 bug（请用 ≥ 1.1.5）。**1.2.0** 起：只有已经回到商品列表后，才会翻商品列表下一页（全量需要这样）。规格匹配页仍然不会点分页。
