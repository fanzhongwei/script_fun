# 规格名称批量粘贴

Tampermonkey 用户脚本：在拼多多商家后台（`mms.pinduoduo.com`）商品规格编辑页，于**第一个**规格名称输入框粘贴多个规格值，脚本按分隔符拆分后依次填入各规格框（含动态增行等待）。

## 环境依赖说明

- **浏览器**：Chrome、Edge 等支持用户脚本的现代浏览器
- **扩展**：Tampermonkey（推荐）或 Violentmonkey
- **权限**：无需 `@grant`，纯 DOM 操作
- **适用站点**：`*://mms.pinduoduo.com/*`（拼多多商家后台商品规格编辑页）

## 脚本参数说明

本脚本为浏览器用户脚本，**无命令行参数**。可在 Tampermonkey 管理面板中查看/编辑以下元数据：

| 元数据 | 说明 | 默认值 |
|--------|------|--------|
| `@match` | 脚本生效的 URL | `*://mms.pinduoduo.com/*` |
| `@run-at` | 注入时机 | `document-idle` |

## 使用配置说明

### 1. 安装脚本

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 打开 `spec_paste.user.js`，Tampermonkey 会提示安装
3. 保存并确保脚本已启用

### 2. 使用流程

1. 打开拼多多商家后台 **商品规格编辑页**
2. 定位到某一规格维度的 **第一个**规格输入框（旧版 placeholder「请输入规格名称」；新版如「自定义尺寸」「自定义重量」等）
3. 从 Excel 或文档复制规格名，例如：`米色,白色,黑色,藏青`；或多规格 SKU 表（Tab 分列），分别粘贴到各维度第一个框
4. 在该第一个框内 **Ctrl+V / Cmd+V 粘贴**
5. 脚本自动拆分并依次填充；填完一项后等待页面出现下一输入框再继续
6. 右上角 toast 提示填充结果（约 3 秒后消失）

### 3. 行为说明

- **仅第一个框触发**：在同组第二个及之后的规格框粘贴时，保持浏览器默认行为，脚本不介入
- **覆盖整组**：粘贴时从第一项起重写整组规格；粘贴项少于已有框数时，多余框会被清空
- **多列 Tab 去重**：从 Excel 复制含 Tab 的多行多列 SKU 表时，粘贴到第 N 个规格维度的第一个框，会自动取第 N 列并按**首次出现顺序去重**（如 12 行组合 → 款式 4 项、尺码 3 项）
- **单列去重**：多行单列粘贴时，同样跳过重复项并保持顺序
- **与价格计算器共存**：本脚本与 `price_calculator` 作用区域不同，可同时安装

### 4. 支持的分隔符

空格、英文逗号 `,`、中文/英文分号 `;` `；`、竖线 `|` `｜`、斜杠 `/` `／`、反斜杠 `\`、顿号 `、`、制表符、换行。

示例均可识别：

- `米色,白色,黑色`
- `米色\n白色\n黑色`（Excel 多行复制）
- 多规格 SKU 表（Tab 分列，见 Q7）
- `米色;白色;黑色`
- `米色|白色|黑色`

## FAQ 说明

### Q1：粘贴后没有自动填充？

- 确认焦点在 **该规格组第一个** 输入框（旧版「请输入规格名称」；新版「自定义尺寸」等）
- 确认 Tampermonkey 中脚本已启用，且当前 URL 为 `mms.pinduoduo.com`
- 粘贴内容需含有效文字，不能仅为分隔符或空白
- 脚本同时支持旧版（`.spec-input`）与新版（`.package-container` / `.custom-input-container`，placeholder 以「自定义」开头）规格 DOM；若仍无效，请反馈输入框 placeholder

### Q2：只填了一部分就提示超时？

页面在填完一项后才渲染下一框。若规格名重复、含敏感词或触发平台校验，可能无法增行。请修正规格名后重试；超时 toast 会显示已填项数与剩余项数。

### Q3：第二个规格框粘贴为什么没反应？

设计如此：批量逻辑 **仅在第一个规格框粘贴时** 触发。若需修改中间某项，请手动编辑该框。

### Q4：粘贴会覆盖已有规格吗？

会。在第一个框粘贴时，整组规格从第一项起按粘贴内容 **覆盖重写**；粘贴项少于已有框数时，后续框会被清空。

### Q5：填充过程中再次粘贴会怎样？

填充进行中会忽略新的粘贴，避免顺序错乱；请等待当前批次完成后再粘贴。

### Q6：如何卸载？

在 Tampermonkey 管理面板中禁用或删除「规格名称批量粘贴」即可。

### Q7：多规格 SKU 组合表如何粘贴？

从 Excel 复制 Tab 分隔的多行数据（如「款式 + 尺码」12 行组合），**同一剪贴板**分别粘贴到各规格维度的**第一个**输入框：

1. 粘贴到第一个维度（如款式）→ 取第 1 列去重：4 项
2. 粘贴到第二个维度（如尺码）→ 取第 2 列去重：3 项

脚本按页面上规格组的 DOM 顺序对应列号，重复值只保留首次出现顺序。
