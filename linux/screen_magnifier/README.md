# 屏幕放大镜

X11 上的轻量圆形放大镜。启动后立刻显示，圆心粘着鼠标指针，并盖在其它窗口上面。再启动一次就隐藏，再启动一次又显示。滚轮改倍率，按住配置的键再滚改直径（默认 Alt），按住 Shift 再滚改算法阈值。

## 环境依赖说明

运行环境必须是 X11 会话（当前 Deepin 桌面的 `XDG_SESSION_TYPE=x11` 即满足），并且桌面合成开着。画面从各个窗口自己的合成像素里读，圆形以外的区域也靠合成才透明。Wayland 会话会直接退出。

构建依赖：

- gcc、make
- X11 开发库：`libx11-dev`、`libxext-dev`、`libxfixes-dev`、`libxrandr-dev`、`libxcomposite-dev`、`libxft-dev`、`libfreetype6-dev`

Debian / Deepin 可一次装齐：

```bash
sudo apt-get install build-essential libx11-dev libxext-dev libxfixes-dev libxrandr-dev libxcomposite-dev libxft-dev libfreetype6-dev
```

运行时只需要这些 X 库和编出来的 `magnifier`，不需要 Python，也不需要额外的 GUI 框架。说明文字会试系统里的中文字体（Noto Sans CJK SC、思源黑体、文泉驿微米黑）。字体缺失时镜头仍会显示，只是不画那行说明。

## 脚本参数说明

`build.sh` 和 `magnifier` 都不接收参数。

```bash
cd linux/screen_magnifier
./build.sh
./magnifier
```

`./build.sh` 会检查 gcc、make、合成与字体相关的头文件和库，然后调用 `make`，成功后打印可执行文件路径。缺依赖时说明缺什么，并以非零状态退出。

桌面快捷键请绑定可执行文件的绝对路径，并设为后台运行，不要放在终端里。第一次按下快捷键会启动进程并立刻显示镜头。再按一次会再启动一个进程，它通知已经在跑的那一份隐藏或显示，然后自己退出。隐藏时会释放整屏画面缓冲和取样缓冲，进程仍留着，再次显示时重新申请。程序不独占快捷键。镜头显示时按 `Esc` 也会隐藏；隐藏之后 `Esc` 和滚轮都不再被占用。右键一直留给下面的程序。需要退出时对进程发 `SIGTERM`。

倍率步进和圆形遮罩可以用 `make test` 单独检查，这个目标不打开窗口。

## 使用配置说明

配置文件是可执行文件同目录下的 `magnifier.conf`。以 `#` 开头的行是说明。第一次运行如果不存在，会按下面的默认值创建；已有文件但没有 `size_key` 时，启动后会补上 `alt` 和说明。

```
# hotkey：建议绑到桌面快捷键上的组合。程序不抓取这个键。
hotkey=ctrl+alt+space
# zoom：放大倍率，范围 1.25 到 6。
zoom=2
# diameter：圆的直径，单位像素。
diameter=360
# filter_zoom：算法阈值，范围 1.25 到 6.25。
filter_zoom=2
# size_key：按住这个键再滚轮改变直径。可选 alt、ctrl、shift、super。
size_key=alt
```

| 项 | 含义 | 默认 |
| --- | --- | --- |
| `hotkey` | 建议绑到桌面快捷键上的组合，程序自己不抓取它 | `ctrl+alt+space` |
| `zoom` | 倍率，1.25 到 6，可以是一位或两位小数 | `2` |
| `diameter` | 圆的直径，像素 | `360` |
| `filter_zoom` | 算法阈值，1.25 到 6.25。当前倍率低于它时直接取像素，不低于时做边缘判断 | `2` |
| `size_key` | 按住这个键再滚轮改变直径。可选 `alt`、`ctrl`、`shift`、`super` | `alt` |

改 `size_key` 后要重新启动放大镜才生效。滚轮写回倍率、直径或阈值时，上面的说明会保留。

以前的 `width` 和 `height` 会在启动时改成 `diameter`，取较小的一边。

镜头显示后：

- 圆心跟着指针，系统箭头隐藏，圆心有一个小点。圆画在一层和整个桌面一样大的透明窗口上，这层窗口不跟着鼠标移动，也不随直径改变大小，显示时一直抬到其它窗口上面。多台显示器共用这一层。贴边时圆心仍在指针上，伸出桌面的部分不显示
- 大约每 16 毫秒从各个窗口自己的画面取样，跳过放大镜这一层。指针停着时，下面的视频和动画也会更新
- 刚显示时，圆的上方出现一行半透明说明 `滚轮倍率 · Alt滚轮大小`（键名跟着 `size_key`），大约 2 秒后消失，底下的内容仍然看得见
- 滚轮向上放大、向下缩小。慢慢转，每一格 0.1 倍；转得快（两格间隔小于约 140 毫秒），每一格 0.5 倍。最低 1.25 倍，最高 6 倍。倍率数字会半透明地在圆里短暂出现，例如 `2.4x`
- 按住 `size_key` 再滚，改的是直径，同时显示上面那行说明和当前直径。默认是 Alt。这一下先画上新圆，只把退出新圆的那一圈擦掉，再一次贴上，圆的内部不会先被涂空，窗口大小也不变。慢慢转每一格 16 像素，转得快每一格 48 像素。最小 96，最大不超过当前显示器的较短边。`size_key` 不是 `ctrl` 时，按住 Ctrl 再滚不改变放大镜，滚动仍送给下面的窗口。配成 `ctrl` 时，Ctrl+滚轮改的是直径
- 按住 Shift 再滚，改的是算法阈值，圆里用两位小数标出，例如 `2.00`。慢慢转每一格 0.25，转得快每一格 0.5。最低 1.25，最高 6.25。当前倍率低于阈值时，每个像素直接取最近的取样，少做一套判断；不低于阈值时，横竖边缘保持原像素，斜线才做过渡。1.25 表示现有倍率都走边缘判断，6.25 表示都直接取像素。若 `size_key` 也是 `shift`，则 Shift 只改直径
- 观看时，圆形里的左键和右键都会落到下面的窗口
- 横竖边缘按原像素保持清晰，斜线只在相邻像素之间做一条过渡。倍率低于 `filter_zoom` 时不做这条过渡

滚轮停下大约 0.2 秒后写回 `zoom`、`diameter`、`filter_zoom`，退出进程时如果还没到这个时间也会写回，说明行会留下来。镜头开着时如果另外保存了 `filter_zoom`，要滚一下倍率才会按新阈值放大，只是重新显示镜头不会去读它。这样写回倍率或直径时，也不会把 `filter_zoom` 改回启动时的数字。跟着指针路过较小的显示器时，直径可能暂时变小，这个临时尺寸不会覆盖原来选定的直径。无法解析的倍率会按 2 倍写回，超出范围会夹到 1.25 或 6。没有 `filter_zoom` 时按 2 写回，超出范围会夹到 1.25 或 6.25。没有 `size_key` 时按 `alt` 写回。

## FAQ说明

**问：快捷键怎么设？**

答：在系统设置里把 `Ctrl+Alt+Space` 绑到 `magnifier` 的绝对路径，运行方式选后台。按一次启动并显示，再按一次隐藏，再按一次又显示。隐藏后进程还在。镜头显示时按 `Esc` 也能收起。

**问：怎么改倍率和大小？**

答：慢慢滚是 0.1 倍，适合停在 2.3、3.5；快速拨轮是 0.5 倍，从 2 倍到 4 倍大约 4 格，到 6 倍大约 8 格。改大小按住 `magnifier.conf` 里的 `size_key` 再滚，默认是 Alt，慢一格 16 像素，快一格 48 像素。按住这个键时，说明和直径会一起出现在圆的上方。想换成 Ctrl、Shift 或 Super，把 `size_key` 改成 `ctrl`、`shift` 或 `super`，然后重新启动。改算法阈值按住 Shift 再滚，慢一格 0.25，快一格 0.5，圆里显示两位小数。当前倍率低于这个数就直接取像素，不低于就做边缘判断。`size_key` 若写成 `shift`，Shift 就只改直径。

**问：镜头里的画面会不会是旧的？**

答：不会整屏缓存。每一拍只读指针周围那一小块，来自各个窗口自己的画面，放大镜自己不在里面。指针停在视频上时，放大画面会跟着换。圆的位置和这幅新画面一起贴上，不会先把旧画面挪走再换新的。改直径时先画上新圆，只擦退出新圆的那一圈，圆的内部不会整块先涂空。

**问：说明文字挡住内容了吗？**

答：那一行是半透明的白字，大约显示 2 秒。按住改大小的键时它和直径数字一起出现。字不接收点击，圆心的小点仍在最上面。

**问：圆的外面是一块黑的？**

答：透明靠桌面合成。合成关掉，或者没有 32 位透明视觉时，程序会提示并退出，不会留下一个不透明方块。请在 X11 会话里开着窗口特效后再运行。

**问：显示镜头时，下面的程序收不到滚轮。**

答：这段时间滚轮用来改倍率，按住 `size_key` 再滚用来改直径，按住 Shift 再滚用来改算法阈值。`size_key` 不是 `ctrl` 时，按住 Ctrl 再滚仍送给下面的窗口。左键和右键仍然点得到下面的窗口。再按一次快捷键或按 `Esc` 隐藏镜头后，滚轮会还给下面的程序。

**问：显示桌面后，圆外面有一块还是旧画面，鼠标移过去才变新的。**

答：放大镜这层平时只提交圆的那一块，合成器就不会重画圆外。其它窗口打开、关闭或移动时，下一拍会把整层再提交一次，圆外马上变成新桌面。请结束旧进程后再启动这一份 `magnifier`，再按快捷键只会切换已经在跑的那一份。

**问：有的窗口会挡住放大镜。**

答：镜头显示时会反复抬到其它窗口上面。请先结束正在运行的旧进程，再启动这一份新的 `magnifier`。只再按一次快捷键只会切换旧进程，不会换成新程序。

**问：`Ctrl+Alt+Space` 会和别的快捷键冲突吗？**

答：常见的输入法切换是 `Ctrl+Space`，窗口菜单多是 `Alt+Space`，输入源或启动器多是 `Super+Space`。`Ctrl+Alt+Space` 通常空着。这个键由桌面快捷键占用，程序不会再抓一次。若要换组合，改桌面快捷键，并让 `magnifier.conf` 里的 `hotkey` 写成同一组，方便以后查看。

**问：全屏游戏或视频里放大出来是黑的。**

答：这类程序如果没有把窗口交给合成器，就读不到它的像素，放大画面会空着或只剩旁边的窗口。回到普通窗口后再用。

**问：按快捷键没有反应，或出现了两个镜头。**

答：快捷键要后台执行这一份 `magnifier`。已经有一份在跑时，再启动会通知它切换，新进程马上退出。若是从终端里手动开了两份，后一份也会去切换前一份，而不是再开一枚镜头。

**问：箭头不见了。**

答：观看时箭头是故意隐藏的，圆心的小点就是指针位置。按 `Esc` 或再启动一次就会恢复。如果进程异常退出后箭头仍不见，结束残留的 `magnifier` 进程。

**问：Wayland 下能用吗？**

答：不能。会话不是 X11，或没有 `DISPLAY` 时，程序提示需要 X11 并以退出码 1 结束。
